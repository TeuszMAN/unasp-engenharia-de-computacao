# Testes

Os casos de teste manuais do jogo serão listados nesta pasta. Cada caso deve informar a entrada digitada, o resultado esperado (mensagem no Run I/O e estado do Bitmap Display) e o resultado obtido.

Para que os testes sejam reproduzíveis, a semente do gerador aleatório (syscall 40) deve ser fixada durante os testes, de modo que os navios do computador fiquem sempre nas mesmas posições.

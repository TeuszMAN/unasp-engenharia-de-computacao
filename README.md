# Engenharia de Computação (UNASP)

Projetos desenvolvidos no curso de Engenharia de Computação do UNASP, campus Hortolândia.

## Projetos

| Projeto | Disciplinas | Resumo |
|---|---|---|
| [Monitoramento de temperatura com ESP32](Embarcados/pi-temperatura) | Projeto Integrador do 8º semestre (Sistemas Embarcados, Sistemas de Controle e Computação Gráfica) | Controle ON/OFF com histerese de um cooler, servidor web no ESP32 e visualização 3D da temperatura em Python |
| [Batalha Naval em MIPS32](ArquiteturaII/batalha-naval-mips) | Arquitetura de Computadores (trabalho em grupo) | Jogo em assembly no simulador MARS, com tabuleiro em matriz de bytes e em bitboard e comparação do número de instruções executadas; em andamento |

## Organização

Cada disciplina tem a sua pasta, e cada projeto fica numa subpasta com o próprio README.

O `.gitignore` funciona como lista branca: só entram no repositório as pastas liberadas nele. Exercícios curtos, materiais de aula e avaliações ficam apenas na máquina local.
